# CariSurg Portfolio

## Headline

Clinical triage data cleaning and AI-assisted emergency decision-support exploration.

---

## Purpose

This repository demonstrates how emergency triage data can be cleaned, analysed, and communicated in a clinically interpretable way, and how AI-assisted workflows can support early-stage healthcare analytics.

---

## Installation

Clone the repository:

```bash
git clone https://github.com/myasymi/carisurg-portfolio.git
cd carisurg-portfolio
```

Install dependencies:

```bash
pip install pandas numpy matplotlib
```

Run in Jupyter Notebook or Google Colab.

---

## Usage

Run in Google Colab

Upload the notebooks to Colab or open directly from GitHub:

- `day_1_gender_cleaning.ipynb`  
- `day_2_rr_data_cleaning.ipynb`  
- `day_3_data_visualisation.ipynb`  

Then click **Runtime → Run all**.
